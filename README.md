# Job Board

A responsive job board application built with React.
The project allows users to browse job opportunities and filter them by keyword and technology.

## Features

- Browse available job opportunities
- Search jobs by:
  - job title
  - company
  - technology
- Filter jobs by technology
- Display the number of available results
- Handle empty search results
- Responsive layout for desktop, tablet and mobile

## Tech Stack

- React
- JavaScript
- Vite
- HTML5
- CSS3
