# Job Board

A responsive job board application built with **React** that allows users to browse and explore job opportunities in the tech industry.

This project is part of my portfolio and is being developed incrementally to simulate a real-world application. It started as a frontend project using static data and will progressively evolve into a full stack application powered by **Laravel**, **MySQL** and a REST API.


## Current Features

* Browse available job opportunities
* Search jobs by:

  * Job title
  * Company name
  * Technologies
* Filter jobs by technology
* View detailed information for each job offer
* Dynamic routing with React Router
* Display the number of matching job offers
* Handle empty search results
* Responsive layout for desktop, tablet and mobile devices

## Getting Started

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
